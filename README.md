# Lula

App Android (Kotlin + Jetpack Compose) de mejora continua personal — hábitos, rutinas, tareas,
metas, finanzas y cuidado familiar.

## Empezar acá

Toda la documentación del proyecto vive en [`Plan/CLAUDE.md`](Plan/CLAUDE.md) — léelo primero,
tiene el resumen del producto, el stack técnico y el índice a los 12 documentos de detalle
(arquitectura, pantallas, vocabulario, roadmap, decisiones técnicas, pendientes, etc.).

Antes de preguntar "¿qué falta?", revisá [`Plan/10-pendientes.md`](Plan/10-pendientes.md) —
tiene la lista viva de qué está bloqueado, qué quedó afuera de una fase, y por qué.
